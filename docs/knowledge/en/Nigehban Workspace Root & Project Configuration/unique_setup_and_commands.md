Run `pnpm install` then `pnpm dev` / `pnpm build` which delegate to Turborepo across all `apps/*` and `packages/*` workspaces. Start infrastructure with `docker compose up -d postgres redis` (exposes Postgres on 5432 and Redis on 6379). Copy `.env.example` to `.env` and fill in `DATABASE_URL`, `REDIS_URL`, `ANTHROPIC_API_KEY`, WhatsApp tokens, search API key, and Cloudflare R2 credentials before running any app.
