# Nigehban Design System

> Locked from Hallmark studied-DNA (Flow craft) · civic remap for Pakistan · **site-wide**.

## Voice
- Display: Instrument Serif (roman only) — short headlines ≤7 words
- Body: DM Sans
- Urdu: Noto Sans Arabic
- Copy: direct, civic, no invented metrics

## Colour
| Token | Role |
|-------|------|
| `--color-paper` `#fdfcf0` | Cream canvas (all pages, light-locked) |
| `--color-accent` `#003e29` | Forest emerald (trust, outlines) |
| `--color-cta` `#e5d4ff` | Lilac primary buttons |
| `--color-canvas-dark` | Charcoal feature bands |
| `--color-canvas-deep` | Forest green proof bands |
| `--color-lilac-wash` | Mid-page CTA band |

## Patterns (marketing + product)
- Shell: MarketingNav + MarketingFooter on every route group
- Cards: `.app-card` — white, 28px radius, soft border
- Titles: `.page-title` / `.page-eyebrow`
- Controls: pill toggles, rounded-full inputs, lilac primary buttons
- Radii: 20–48px; no utilitarian small-radius chrome

## Structure
- Macrostructure: Marquee Hero + product demos + statement close
- Nav: N1b with lilac CTA
- Footer: Ft5 + giant wordmark
- Motion: path draw, fade-up, marquee (reduced-motion safe)
